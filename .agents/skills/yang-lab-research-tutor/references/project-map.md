# 项目地图：一个问题只找必要的文件

项目根：使用当前研究项目目录。下面课程路径均相对`资料库/`。

## 谁维护什么

| 信息 | 唯一维护位置 |
|---|---|
| 教学、批改和核验规则 | 本Skill及其对应参考 |
| 论文顺序、各阶段目标 | `04_正式学习路线/01_阶段总路线.md` |
| 当前学习入口 | `04_正式学习路线/08_当前学习入口.md` |
| 能力与过程摘要 | `04_正式学习路线/02_学习状态表.md` |
| 具体作答与评估证据 | `08_测评与复盘/<论文>/` |
| 整篇正式验收条件 | `04_正式学习路线/07_讲图与答辩验收标准.md` |
| 可复制启动指令/用户操作说明 | `00_总Prompt.md`、`10_MD单文件学习工作流.md`，仅作入口与摘要，不另建规则体系 |

不要将“当前第几讲、某题错了什么”写进通用Skill或总Prompt。历史版本的记录保留并注明时点；摘要链接到最新评估，不在每份文件复制整份批改。

## 按任务读取

- 恢复上下文、生成下一讲：当前入口→其指向的最新评估；涉及选题时核对对应原始作答，不能只听历史评价。只有改变论文安排才读完整阶段路线。
- 批改：实际提交文件＋对应题目/教材；核验相关原文或实现。阅卷前检查题目版本，不评估用户未要求提交的其他答案。
- 普通答疑/改段：目标位置及必要上下文即可，不读全套路线或更新能力表。
- 进度询问：状态与证据，注明未评估项；不把读取新文件当成提交授权。
- 正式验收：再读验收标准。课程推进不等于触发一次完整验收。
- Skill维护：检查现行调用文档，消除冲突而不修改历史证据；不动无关准备记录。

## 来源与产物目录

原始课题组要求在根目录`2026年-生成部分论文阅读.pdf`；来源清单`00_索引/资料总表.md`。原文`01_论文原文/`、辅助网页`02_网页原始内容/`、定位正文`03_可检索正文/`。

教学产物放`05_逐篇论文精读/<论文>/`，图片放其assets；长推导确有需要才独立放`06_数学推导讲义/`；可运行代码/记录放`07_代码实践/<论文>/`；独立作答与评估放`08_测评与复盘/<论文>/`。

优先更新现有对应教材、评估和入口。只有独立新主题或必要的历史留档才新建文件，不为每次反馈增加同义计划/总结。
