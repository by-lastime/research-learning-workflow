# 数学、shape与代码：最短的可理解计算链

## 先定位具体卡点

区分对象身份、轴含义、操作原理、语法、调用顺序与训练状态。只补实际缺失的桥梁，不因代码不懂一律退回Python基础，也不直接贴更多源码。

主线使用“图中动作 → 短代码 → 输入/输出 → 下一步”。每段一个动作，首次说明函数实参、返回值与必要语法；先教机制，再放加载模型、路径、日志、依赖安装等辅助内容。参数字典、日志还原、detach/clone若不是本讲目标，不占据开头。

稳定使用同一例子和变量。区分伪代码、依赖已定义输入的实现摘录与独立程序；摘录列明前置对象及省略边界。不要用脱离梯度图的日志重建值来冒充完整训练链。

## shape与公式

- 行内`$...$`，独立`$$...$$`；解释符号、条件、索引、求和/归一化轴。定义就近出现，避免为了保留“公式部分”而让前文符号悬空。
- 先说轴的对象，再说长度：位置、头、特征、样本和候选不可混同。区分参数shape、中间值shape、权重表与词表表；同shape不代表同对象。
- 矩阵乘法说明哪个轴求和、哪些轴留下；切片/拼接/广播解释发生在哪个轴，不止给结果。
- 前向算中间值，backward求并累积梯度，更新语句修改参数，生成追加输入；按本讲需要追踪变化前后，不重复整份实现。

## 数值例子的完整性边界

先声明起点、终点、输入、配置/参数及与论文差异，再实际计算到承诺终点。完整模型演示不能省核心模块；完整生成/训练演示应真实衔接前缀、损失、梯度和更新。禁止手设H、注意力权重或成功输出冒充模型结果。

可以用完整的局部模型解释一个问题，但要明确它不是整篇模型的替代品。单参数示例、给定shape变式、真实模型运行三者分开。用户要求完整模型全流程或单文件全部中间量时，不以局部例子或外链替代。

长数值默认折叠，保存可执行脚本与全精度记录，展示值注明舍入。复用同次已验证记录时注明版本/配置，避免不同长度、参数和训练前后状态混用。已存在实验记录不因备课复跑而覆盖；新实验另存，重复验证可仅比较输出。

## 验证到相应风险为止

新代码/改动代码执行有关的最小检查：对象和shape、遮挡/信息来源、参数与梯度状态、输出与参考实现/记录一致性等。没有改变计算的纯文字编辑不强制重跑模型。

记录真实输入、参数或随机性、版本、结果、控制变量和结论边界；程序跑通不等于复现论文质量，不等于用户会独立实现。不要为验证一个局部点启动未请求的大规模训练、权重下载或完整复现。
