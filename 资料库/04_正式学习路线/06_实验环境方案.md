# 阶段 0 实验环境方案

> 历史准备方案，以下检测为当时结果；后续建立环境的记录见 `07_代码实践/00_阶段0基础补缺/`。2026-09-05 本次教学重启未重新验证环境。

## 当前检测结果

- 操作系统：macOS
- 系统 Python：3.9.6
- 默认系统 Python 中缺少 PyTorch、NumPy、Matplotlib、Jupyter
- Codex bundled Python：3.12.13，已有 NumPy，缺少 PyTorch、Matplotlib、Jupyter
- Git：已安装
- 本地 NVIDIA GPU：无
- 云 GPU：可按需要使用

## 环境策略

不使用系统 Python 直接堆积依赖。为学习项目建立独立虚拟环境，并保存依赖文件。

环境需要支持：

- Python
- PyTorch
- NumPy
- Matplotlib
- JupyterLab
- pytest
- 后续阶段再按需要增加 diffusers、transformers、accelerate、safetensors 等依赖

早期张量、Attention 和小型训练任务使用 CPU 或 Apple MPS 即可。Stable Diffusion 与较大模型实验再单独配置云 GPU 环境，避免当前阶段引入不必要的复杂度。

## 环境验收

环境建立后必须通过：

1. 导入 torch、numpy、matplotlib。
2. 输出 Python 与 PyTorch 版本。
3. 检测 CPU/MPS 设备。
4. 完成一次张量乘法与自动求导。
5. 启动 Notebook。
6. 使用 pytest 运行一个最小测试。

在用户明确开始环境任务时再执行安装，避免未经确认改变现有 Python 环境。
